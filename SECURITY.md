# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.2.x   | ✅        |
| 0.1.x   | ❌        |

## Reporting a Vulnerability

Please do not report security vulnerabilities via public GitHub issues.

Report vulnerabilities via this repository's Security tab (GitHub private advisory feature).

Include: description, reproduction steps, affected versions, and impact assessment.

**Response timeline:** Acknowledgement within 48 hours. Patch or mitigation within 14 days for confirmed issues.

## Scope

This policy covers vulnerabilities in the `osintdepintel` tool itself. It does not cover findings the tool produces about third-party targets.

## Safe Harbour

This project is a passive OSINT research tool. It makes only GET requests to public URLs and APIs. No active scanning, exploitation, or credential use is performed.
